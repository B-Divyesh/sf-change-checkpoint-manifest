# Change Checkpoints design thesis

## Direction

**Dithered / halftone print system.** A checkpoint is a physical proof sheet: a
fixed snapshot of a change, its test marks, and a clearly printed way back.
The site uses dense ink fields, registration rules, and stamped status labels
instead of the polished glass panels common to developer tools.

## Tokens

| role | value | use |
| --- | --- | --- |
| paper | `#f4efdf` | warm page ground |
| ink | `#17212b` | headings and body, 14.1:1 on paper |
| muted ink | `#48515a` | secondary copy, 6.9:1 on paper |
| red stamp | `#a7312e` | the action and failed checks |
| red ink | `#fff8ed` | action label |
| green proof | `#23634d` | passing checks |
| night | `#101720` | terminal and dark treatment |
| rule | `#c8bfae` | print rules and borders |

Headlines use the self-hostable system `ui-monospace` stack so hashes and
commands hold their shape. Body text uses `system-ui` for long reading. The
type scale is 12 / 14 / 16 / 20 / 28 / 52px with a 1.35–1.55 leading range.

Spacing is an 8px scale. Layouts use one wide proof-sheet column with an
offset terminal slip, then collapse to one column below 720px. Corners are
square; borders and dotted patterns establish grouping instead of generic
rounded cards.

On a 390px screen, the demo disclosure becomes a compact two-row ink strip.
Its status occupies the first row, while Reset and exit remain 44px targets on
the second. This keeps the sandbox boundary visible without covering the
sample record. Safe-area insets extend the page and banner padding on notched
screens.

## Interaction and motion

The signature detail is a small halftone inspection field that reveals its
dot pattern on hover and a terminal cursor that types one short command. Both
are opacity/transform only and stay under 220ms. With reduced motion, the
field is static and the command is fully shown immediately. Focus rings are a
solid red outer rule.

The product offers a deliberate dark terminal view as part of the proof-sheet
system; it is not a separate brand. The page ground remains explicit in both
states.

## Original artwork

`site/src/assets/checkpoint-press.webp` is a generated editorial illustration:
a developer-workbench proof sheet with a git diff, verification marks and
halftone ink texture. It contains no text that visitors must read. It was
generated by `/opt/fleet/lib/gen-image.sh` using the factory image deployment;
`.factory/art/checkpoint-press.png.json` records the prompt and generation
settings. The image is converted to WebP for delivery and constrained below
300 KB.

`site/src/assets/demo-recording.svg` is a hand-made terminal recording based on
the output of the bundled `cpc demo` command. It is self-hosted and repeats no
essential text that is unavailable in the adjacent HTML demo.
